## What changed v0.17.0 → v0.18.0 (context for this round)

Pure parity bump — the cleanest so far. Phase 1 drift re-check (fresh v0.18 extraction vs preserved v0.17 source) found:

- `config/default/` **byte-identical** → extraction entrypoint unchanged, no generator algorithm changes.
- **One new ConfigMap key** `disableHTTPRouteTimeout` (default `false`) in the ingress block. Our ConfigMap patch is parse-modify-reserialize, so it flows through untouched — verified present in regenerated `p-kserve-raw/`.
- `config/rbac/role.yaml` gains `localmodelnamespacecaches` inside the **kept** `kserve-manager-role` — survives as a harmless get/list/watch grant on an uninstalled CRD (RBAC doesn't validate resource existence). Zero functional impact.
- `kube-rbac-proxy:v0.18.0` unchanged from v0.17; controller image name unchanged (only pin tag flips); DROP filter still catches everything (config/crd builds the identical 6 core CRDs).
- **NEW admission validator (T33):** `pkg/validation/env_policy.go`, `DefaultBlockedEnvVars = ["PYTHONPATH"]`. Rejects any container (across predictor / transformer / explainer / WorkerSpec / InitContainers on `InferenceService`, and `ServingRuntime`/`ClusterServingRuntime`) that sets `PYTHONPATH`, with `setting PYTHONPATH in container "X" is not allowed for security reasons`. Same shape of "new validator breaks charts written against the older version" as the v0.15→v0.16 scaleMetric break — hence T33 + a Part D Troubleshooting entry (Phase 6). No impact on our shipped `sklearn-iris.yaml` sample (it sets no `PYTHONPATH`).

Retarget commit: `813c310 chore(generator): retarget extraction at KServe v0.18.0`.

### T33 — PYTHONPATH blocked-env-var validator guard (NEW in v0.18)

**Purpose:** Lock in the new v0.18 admission validator (`pkg/validation/env_policy.go`, `DefaultBlockedEnvVars = ["PYTHONPATH"]`). Same shape as T31 (scaleMetric): a negative + positive pair that fails loudly if upstream ever removes or loosens the validator, keeping the Part D Troubleshooting doc from rotting silently. Cluster test, ~5 min.

**Source anchor (verified Phase 1, v0.18 tree):**
- `pkg/validation/env_policy.go:38` — error `setting %s in container %q is not allowed for security reasons`.
- `pkg/apis/serving/v1beta1/inference_service_validation.go:200` — `validateBlockedEnvVars(isvc)` iterates predictor/transformer/explainer containers + InitContainers + WorkerSpec.

**Recipe:**
1. Cluster reset (verify fresh via node `creationTimestamp`).
2. Install KServe (default flow, `v18001` OLM bundle or `install.sh` — either exercises the same validating webhook). Wait controller `2/2 Running`, then confirm the webhook HTTPS server on 9443 is actually listening (in-cluster curl probe, per [[enable-ingress-webhook-probe]]) before applying — a Ready pod ≠ Ready webhook.
3. **NEGATIVE case:** `kubectl apply` an ISVC in `default` ns whose predictor sets `PYTHONPATH` on a container, e.g.:
   ```yaml
   apiVersion: serving.kserve.io/v1beta1
   kind: InferenceService
   metadata:
     name: t33-pythonpath-neg
     annotations:
       serving.kserve.io/deploymentMode: "Standard"
   spec:
     predictor:
       containers:
         - name: kserve-container
           image: kserve/sklearnserver:v0.18.0
           env:
             - name: PYTHONPATH
               value: /custom
   ```
   → expect **exit ≠ 0**, stderr containing `not allowed for security reasons` (and naming `PYTHONPATH` + the container).
4. **POSITIVE case:** same ISVC without the `PYTHONPATH` env var (drop the whole `env:` block, or use the standard `sklearn-iris` storageUri form) → expect **exit 0**, `READY=True` within 2 min.
5. `kubectl get isvc t33-pythonpath-pos` shows `READY=True`; curl the positive ISVC → `{"predictions":[1]}` (single-instance payload, like T31).

**Pass criteria:** negative case rejected at admit time with the exact `not allowed for security reasons` message; positive case Ready + inference succeeds. Cross-links to Part D Troubleshooting (Phase 6) + `kserve-version-comparison.md` § v0.17→v0.18 downstream compatibility (Phase 6) + [[kserve-017-to-018-pythonpath-env-block]] memory.
